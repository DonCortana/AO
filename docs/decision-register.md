| D-037 | 2026-08-27 | The §6.2 hierarchical paired bootstrap is implemented on the standard library's `random.Random` (Mersenne Twister) with a caller-supplied seed that is required, not optional, and is returned with the result for storage alongside the score row. | D-038 | 2026-08-27 | Methodology §6.2 specifies the hierarchical paired bootstrap in one sentence that is under-determined in four ways, each of which changes the reported interval. Resolved before implementation. (a) **What is paired:** one prompt-ID draw is made per resample and applied to *both* periods, which is what "Baseline and validation are recomputed within the same bootstrap draw" requires; replicate observations are then resampled independently within each period, because replicate 3 of a baseline run and replicate 3 of a validation run are not the same unit and pairing them would be fiction. This is load-bearing and was measured by controlled A/B against the shipped implementation — identical data, identical seed, 10,000 resamples, the *only* difference being whether one prompt draw feeds both periods (`movement.py:199-208`) or each period draws independently. Median 95% CI width at 40 prompts x 4 platforms x 5 replicates: **4.93 AVS points paired vs 15.82 unpaired, a 3.2x inflation**; the ratio holds across scales (2.4x at 12 prompts, 2.9x at 20, 3.3x at 80). On one representative cycle the paired interval is (+4.62, +9.61), which excludes 0 and returns Improvement, while the unpaired interval on the same data is (-1.12, +15.31), which includes 0 and can only return Inconclusive — so the choice decides whether an MRC-5.0 movement is reportable at all. (An earlier uncontrolled estimate put the unpaired width near 26 points; it came from a diagnostic that also varied tier count and the pairing of the underlying data, and is superseded by the A/B figures above.) (b) **Repeated prompts:** a prompt drawn k times in one resample gets k independent replicate resamples, the standard hierarchical treatment. (c) **Empty cells:** a prompt-platform cell holding no scoreable replicate in a given draw is dropped from that PlatformScore's intent-weighted mean and its weight removed from the denominator, rather than imputed as zero — a technical or parsing gap is never scored as an absence (Operating System §1). (d) **Unpaired prompts:** the resampling frame is the intersection of prompts observed in both periods; a prompt present in only one period cannot contribute to a paired delta, is excluded from the frame, and is reported in the result so the exclusion is visible rather than silent. Additionally the reported point-estimate delta is computed from the observed data, not taken as the mean of the bootstrap distribution, and "95% CI excludes 0" is evaluated strictly (a bound of exactly 0.0 includes 0, so the verdict is Inconclusive). Interval calibration was checked by simulation against a known population delta: 98.0% coverage at a nominal 95% over 300 simulated cycles — slightly conservative, the safe direction for a reporting threshold. | Active |

| D-047 | 2026-08-27 | Rank collapse for a co-mentioned prompt-platform cell is the **median rank across that cell's mentioned replicates**, computed per layer, on the same cells D-045 collapses for mention agreement. Reason: D-045 fixed the unit of analysis as the cell and specified the *mention* collapse (majority vote) but not the rank collapse, and Spearman rho needs one rank value per cell per layer — majority vote does not produce one. The gap was found while implementing D-045, not in review, and it changes a reported §8.4 statistic, so it is settled here rather than left to the code. Median is chosen because rank is ordinal: a position is a place in a list, not a quantity, so an arithmetic mean over positions asserts a spacing the data does not carry (the distance from rank 1 to rank 2 is not the same kind of thing as the distance from rank 9 to rank 10, and §4.1's own RPV table prices those gaps very differently — 1.00 -> 0.80 versus 0.25 -> 0.25). Median is additionally robust to a single outlying replicate, which matters at n=5 and n=3 where one anomalous deep placement would drag a mean several positions and misrepresent a cell that was otherwise stable. The choice is deliberately low-stakes by construction: the collapsed ranks feed only Spearman, which re-ranks its inputs before correlating, so **only relative ordering between cells survives the collapse** — any monotone-preserving summary of a cell's replicates would give the same rho, and median is the one that is also a real observed position in the odd-count case. Rejected: the mean (imposes interval spacing on ordinal data); the best (minimum) rank (systematically flatters the client by reporting its luckiest replicate); the modal rank (undefined or arbitrary whenever replicates disagree, which is the normal case). Even-count ties resolve as `statistics.median` does, by averaging the two middle positions — a non-integer cell rank is acceptable precisely because only ordering is used downstream, and no client-facing number reports a cell rank directly. Replicates that were not mentions contribute no rank and are excluded from the median rather than entering it as a sentinel; a cell whose majority judgment is absent carries no rank at all. This decision changes how a cell's rank *value* is derived and nothing about the statistics themselves — the kappa and Spearman implementations, and their verification against sklearn 1.9.0 and scipy 1.18.1 recorded under D-045, are untouched. | Active |
